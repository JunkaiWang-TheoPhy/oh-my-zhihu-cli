# Terminal sprite sources

The runtime assets are derived, low-resolution terminal sprites rather than copies of official artwork.
They are downsampled with a sharp nearest-neighbor presentation, posterized, background-separated, and rendered with terminal half-blocks.
The six source images were supplied as visual references in the project conversation.
